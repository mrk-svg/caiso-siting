# Authorship, AI use, and what that means for copyright

This project was built by Robert Karimov working with agentic AI tools. That is stated here
plainly rather than discovered later, because a data product whose whole claim is traceability
cannot be evasive about how it was produced.

## Who did what

**Human (the author).** Scope and purpose. Every domain judgment: which CAISO files matter and
which do not; that a deliverability *request* is not an *allocation*; that TPD refusals only carry
meaning once split by allocation group; that Cluster 14 and Cluster 15 ran under different
processes and their survival curves cannot be plotted as one series; that a substation named as
delineating a local capacity area is not thereby inside it; which figures may be published and
which must stay marked "Not public". Reading the primary filings. Accepting or rejecting every
proposed feature — several were rejected outright because they would have required inventing
numbers the public record does not support. Review, correction, and the decision to publish.

**AI tools.** Most of the Python. Draft documentation. Adversarial review passes over the author's
own code and data, run deliberately to find errors the author's assumptions would not catch —
which is how the EIA-860 distance-join defect, several local-capacity encoding errors, and a set
of wrong substation coordinates were found.

**Neither.** No figure on any page or in any output was written by a human or generated by a
model. Every one is computed from a published filing and carries the file and run date it came
from. Where the filings do not support a figure, the product says so instead of estimating.

## Why the division matters

AI-assisted code fails differently from code written by hand. It does not usually crash; it
produces a plausible wrong answer, and the tests generated alongside it encode the same mistaken
assumption, so they pass. The defences this project uses against that are the provenance columns
on every output row, explicit review passes whose only job is to find errors, and a published
register of known defects (`KNOWN_ISSUES.md`). None of them makes the output correct. They make it
checkable, which is the most any tool built this way can honestly claim.

## Copyright position

The source code is offered under the MIT Licence and the outputs under ODbL 1.0
(see `LICENSE`, `LICENSE-DATA.md`).

Two limits are worth stating rather than glossing:

**Upstream data is not ours.** CAISO, the EIA, PG&E, the CEC and the counties own or publish the
underlying material on their own terms, and this project's licences cannot and do not purport to
grant rights in it. `DATA_LICENSES.md` records each source's terms and the attribution it
requires; `outputs/ATTRIBUTION.txt` carries that attribution with the files themselves.

**Machine-generated material may not carry copyright.** Under current United States practice,
material produced by an AI system without sufficient human authorship is generally not
copyrightable, and copyright subsists only in the parts a human authored or in the human's
selection and arrangement of the whole. This repository therefore makes no claim beyond what the
law allows: the MIT grant is offered over the work as a whole and is not an assertion that every
line of it is a protected work. In practice this changes nothing for anyone using the project —
MIT is permissive, so the practical permission is the same either way — but it is stated so that
no downstream user relies on a claim this project is not in a position to make. This is a
description of the author's understanding, not legal advice; anyone whose use depends on the
answer should take their own.

Third-party components keep their own licences: Leaflet is BSD-2-Clause and its licence travels
with it in `src/caiso_siting/vendor/`.

## Contributions

Contributions are welcome, including from people who use AI tools to make them — on the same terms
the author holds himself to. Code is contributed under MIT and data under ODbL. Every changed row
in a hand-built data file needs a public source and a date. A number that cannot be traced to a
filing does not go in, whoever or whatever wrote it. `CONTRIBUTING.md` has the detail.
